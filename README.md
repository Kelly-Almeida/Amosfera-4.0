# Projeto Atmosfera 4.0 ☁️ - Equipe DEV

## 📖 Introdução e Contextualização
O **Atmosfera 4.0** é um projeto interdisciplinar idealizado na Escola SENAI “Anchieta” pelo Profº Lucas Felfoldi. O objetivo principal do projeto é montar, instalar, programar, monitorar e manter sensores ambientais espalhados pela escola, criando uma **estação meteorológica comunitária**. Esta iniciativa visa desenvolver o sentimento de pertencimento nos alunos através da aplicação prática da tecnologia e do trabalho em equipe.

O projeto integra turmas dos cursos técnicos em:
* Desenvolvimento de Sistemas
* Eletrônica
* Mecatrônica
